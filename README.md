# ESP32 Mesh Network

A small embedded networking project implementing a multi-node mesh network using ESP32 microcontrollers.

The network consists of regular nodes and a dedicated gateway node. Nodes exchange data through a mesh network, while the gateway additionally connects to an external Wi-Fi network and uploads collected data to Yandex Disk.

## Overview

The project demonstrates a practical implementation of a mesh network using ESP32 and the [PainlessMesh](https://gitlab.com/painlessMesh/painlessMesh) library.

Each node periodically generates a message containing its identifier and the current time. Messages are transmitted through the mesh network and received by the gateway node.

The gateway acts as a bridge between the mesh network and an external Wi-Fi network:

```text
┌─────────────┐
│  ESP32 Node │
└──────┬──────┘
       │
       │ Mesh
       ▼
┌─────────────┐      Mesh       ┌─────────────────┐
│  ESP32 Node │ ──────────────► │ Gateway ESP32   │
└─────────────┘                 └────────┬────────┘
                                        │
                                        │ Wi-Fi
                                        ▼
                                ┌─────────────────┐
                                │  Yandex Disk    │
                                │   JSON file     │
                                └─────────────────┘
```

## Features

* ESP32-based mesh network
* Multiple nodes communicating through PainlessMesh
* Unique identifier for each node
* Periodic transmission of node data
* Timestamp generation and synchronization
* Dedicated gateway node
* Gateway connection to an external Wi-Fi network
* Collection of messages received from mesh nodes
* JSON-based data storage
* Upload of collected data to Yandex Disk
* HTTP communication using `HTTPClient`
* Experiments with communication distance and antenna orientation

## Network Architecture

The system contains two types of nodes.

### Regular Node

A regular node:

1. Initializes the mesh network.
2. Obtains its unique identifier.
3. Maintains its connection to the mesh.
4. Generates periodic messages.
5. Sends its identifier and current time through the mesh.

The mesh itself is managed by the PainlessMesh library, which handles communication between nodes.

### Gateway Node

The gateway has an additional responsibility.

Besides participating in the mesh network, it connects to an external Wi-Fi network and communicates with Yandex Disk.

Its general workflow is:

```text
Mesh messages
     │
     ▼
Receive data
     │
     ▼
Collect messages
     │
     ▼
Build JSON data
     │
     ▼
HTTP request
     │
     ▼
Yandex Disk
```

This makes the gateway a bridge between the local mesh network and an external network service.

## Communication

The application-level messages contain information about the node that generated them and the time associated with the message.

The mesh communication itself is handled by PainlessMesh, while the application code is responsible for generating, processing, and forwarding the data.

The project uses callbacks provided by the mesh library to handle incoming messages and network events.

## Time Synchronization

Time is used as part of the data generated by each node.

The gateway obtains the current time and distributes the relevant time information through the mesh, allowing nodes to include timestamps in their messages.

The implementation uses network-based time synchronization rather than relying solely on the local ESP32 clock.

## Data Storage

The gateway collects received messages and prepares them for external storage.

The data is represented in JSON form before being uploaded to Yandex Disk.

The resulting data conceptually follows the structure:

```json
[
    {
        "node_id": "12345",
        "timestamp": "2023-10-01 12:34:56"
    },
    {
        "node_id": "67890",
        "timestamp": "2023-10-01 12:35:06"
    }
]
```

The exact internal representation is determined by the current implementation.

## Yandex Disk Integration

The gateway uses an external Wi-Fi connection to communicate with Yandex Disk.

The upload process is implemented using HTTP requests:

```text
ESP32 Gateway
     │
     │ Wi-Fi
     ▼
HTTPClient
     │
     │ HTTPS request
     ▼
Yandex Disk API
     │
     ▼
mesh_data.json
```

The gateway periodically collects messages and sends the resulting data to cloud storage.

This part of the project demonstrates how an embedded device can act as a gateway between a local wireless network and an external HTTP API.

## Mesh Communication

The project uses [PainlessMesh](https://gitlab.com/painlessMesh/painlessMesh) to provide the mesh networking layer.

The application does not implement the mesh routing algorithm itself. Instead, it uses the functionality provided by the library and focuses on the application-level communication between nodes and the gateway.

This allows nodes to communicate without requiring every node to have a direct connection to the gateway.

## Experimental Evaluation

The project also included practical experiments to evaluate the stability of wireless communication under different conditions.

The experiments investigated the influence of:

* distance between nodes;
* antenna orientation;
* number of nodes in the communication chain.

The results showed a significant influence of antenna orientation on the maximum observed communication distance.

Under the tested conditions, communication was possible at distances of approximately **110 m** with a favorable antenna orientation, while an unfavorable orientation reduced the observed distance to approximately **35 m**.

A chain of multiple ESP32 nodes demonstrated how a mesh network can extend the overall communication area beyond the direct range of a single node.

These results are specific to the hardware, environment, and experimental conditions and should not be interpreted as universal ESP32 communication ranges.

## Project Structure

The repository contains the firmware and supporting files required to run the mesh network nodes and gateway.

The main application logic is divided according to the responsibilities of the nodes:

* mesh initialization and configuration;
* node communication;
* gateway functionality;
* time handling;
* Wi-Fi connection;
* HTTP communication with Yandex Disk;
* message collection and data processing.

## Project Background

This project was developed as a university assignment focused on wireless networks and embedded systems.

The main goal was to build a working mesh network using ESP32/ESP8266 devices and investigate its practical communication characteristics.

Unlike a purely simulated networking project, the implementation was tested on physical microcontrollers and included experiments with communication distance and antenna orientation.
